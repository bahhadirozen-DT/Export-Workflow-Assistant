# Export-Workflow-Assistant

Akreditif ve dış ticaret evraklarını analiz ederek gerekli belgeleri çıkaran operasyon destek sistemi.

## Özellikler

- PDF okuma
- DOCX okuma
- OCR (JPG/JPEG/PNG)
- LC belge tespiti
- Checklist hazırlama (yakında)

## Çalıştırma

```bash
pip install -r requirements.txt
streamlit run app.py
